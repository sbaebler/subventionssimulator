1. Zweck der Applikation

Der Subventionssimulator ermöglicht es der Zurich Sailing Federation, verschiedene Sportsubventionen (J+S, NWF, kantonal, vereinsintern) zu erfassen und für ein konkretes Trainings- oder Lagerprojekt den erwarteten Förderbeitrag zu berechnen.

Die Applikation ist in zwei Phasen aufgebaut:

  • Phase 1 – Erfassung: Subventionen mit allen Betragsregeln, Trainerarten und Eventarten pflegen
  • Phase 2 – Simulation: Für ein konkretes Event (Teilnehmer, Tage, Trainer, Eventtyp) den Beitrag aller passenden Subventionen berechnen

2. Datenmodell (Übersicht)

Jede Subvention besteht aus Stammdaten und drei Detail-Tabellen:

subventionen Stammdaten
└──
subvention_betraege Betragsregeln (1..n pro Subvention)
└──
subvention_trainerarten Erlaubte Trainerarten + Zusatzbetrag
└──
subvention_eventarten Erlaubte Eventarten + Multiplikator

Alle Detail-Tabellen sind via subvention_id mit der Haupttabelle verknüpft (CASCADE DELETE).

3. Subventions-Stammdaten

Tabelle subventionen

Feld Typ Pflicht Beschreibung
bezeichnung VARCHAR(200) Ja Name des Subventionstopfs, z.B. «J+S Lagerbeitrag Segeln»
foerderstelle VARCHAR(150) Ja Herausgebende Organisation, z.B. «BASPO / J+S», «Kanton ZH»
kategorie ENUM Ja Thematische Einordnung – siehe Abschnitt 10
beschreibung TEXT Nein Freitextbeschreibung für die Übersichtsansicht
voraussetzungen TEXT Nein Fördervoraussetzungen (Freitext), z.B. Mindestalter, Mitgliedschaft
gueltig_von DATE Nein Startdatum der Förderfähigkeit (NULL = unbefristet)
gueltig_bis DATE Nein Enddatum – Subventionen nach diesem Datum erscheinen nicht in der Übersicht
antragsfrist DATE Nein Datum bis wann der Antrag eingereicht werden muss (nur informativ)
link_extern VARCHAR(500) Nein URL zur offiziellen Förderseite
aktiv TINYINT(1) Ja 0 = deaktiviert (erscheint nicht in Übersicht/Simulator)

4. Betragsregeln

Tabelle subvention_betraege – eine Subvention kann mehrere Regeln haben (aktuell wird die erste Regel für die Berechnung verwendet)

Feld Typ Standard Beschreibung
bezeichnung VARCHAR(100) Standardbetrag Name der Regel, z.B. «J+S Lagerpauschale»
grundbetrag DECIMAL(10,2) 0.00 Fixer Sockelbetrag in CHF, unabhängig von TN-Zahl oder Tagen
betrag_pro_teilnehmer DECIMAL(8,2) 0.00 Betrag in CHF pro Teilnehmer
betrag_pro_tag DECIMAL(8,2) 0.00 Betrag in CHF pro Tag (unabhängig von TN-Zahl)
max_teilnehmer SMALLINT 0 0 = kein Limit. Sonst: maximale TN-Zahl die in die Berechnung einfliesst
max_tage SMALLINT 0 0 = kein Limit. Sonst: maximale Tagezahl die in die Berechnung einfliesst
betrag_max_gesamt DECIMAL(10,2) 0.00 0 = kein Limit. Sonst: absoluter Maximalbetrag (Cap) in CHF

5. Trainerarten

Tabelle subvention_trainerarten – definiert welche Trainerarten für eine Subvention förderberechtig sind

Feld Typ Beschreibung
trainerart ENUM Schlüssel der Trainerart – siehe Tabelle unten
zusatzbetrag DECIMAL(8,2) Zusätzlicher CHF-Betrag für diese Trainerart (wird zum Subtotal addiert, vor dem Eventart-Multiplikator)
bemerkung VARCHAR(300) Optionaler Hinweis, z.B. «Nur mit gültigem J+S-Ausweis»

Mögliche Werte für trainerart:

Schlüssel Bezeichnung Bedeutung
js_trainer J+S Trainer Trainer mit gültiger J+S-Anerkennung (Jugend+Sport, BASPO)
nwf_trainer NWF Trainer Trainer mit Anerkennung im Rahmen der Nachwuchsförderung
ohne Trainer ohne Anerkennung Kein spezifischer Ausweis erforderlich – Vereinstrainer etc.
Wichtig: Ist die Trainerart des simulierten Events nicht in der Liste der erlaubten Trainerarten einer Subvention, wird die Subvention als nicht berechtigt zurückgegeben – unabhängig vom Betrag.

6. Eventarten

Tabelle subvention_eventarten – definiert für welche Eventtypen eine Subvention gilt

Feld Typ Beschreibung
eventart ENUM Art des Events – siehe Tabelle unten
multiplikator DECIMAL(5,3) Faktor auf den Subtotal (1.000 = keine Änderung, 1.200 = +20% Bonus, 0.800 = −20%)
bemerkung VARCHAR(300) Optionaler Hinweis, z.B. «Mindestdauer 3 Tage»

Mögliche Werte für eventart:

Schlüssel Bezeichnung Bedeutung
lager Lager Mehrtägiges Trainingslager mit Übernachtung
training Training Einzeltraining oder kürzerer Trainingsblock ohne Lagercharakter

7. Simulationsparameter (Eingabe)

Der Benutzer gibt für ein konkretes Event folgende vier Parameter ein. Der Simulator berechnet dann den Förderbeitrag für alle passenden Subventionen.

Parameter Typ Beschreibung
anzahl_teilnehmer integer ≥ 0 Anzahl Teilnehmende am Event (Sportler, ohne Trainer)
anzahl_tage integer ≥ 0 Dauer des Events in Tagen
trainerart ENUM Art des eingesetzten Trainers (js_trainer / nwf_trainer / ohne)
eventart ENUM Art des Events (lager / training)

8. Berechnungsformel

Die Berechnung läuft in drei Schritten: Berechtigungsprüfung, Betragskalkulation, Deckelung.

Schritt 1

Berechtigungsprüfung

1a. Ist die eingegebene Trainerart in der Liste der erlaubten Trainerarten dieser Subvention?
→ Nein: Ergebnis = nicht berechtigt (Grund: «Trainerart nicht berechtigt»)

1b. Ist die eingegebene Eventart in der Liste der erlaubten Eventarten dieser Subvention?
→ Nein: Ergebnis = nicht berechtigt (Grund: «Eventart nicht berechtigt»)

→ Ja für beide: weiter zu Schritt 2

Schritt 2

Betragskalkulation

// Effektive Grössen (Obergrenzen anwenden)

eff_TN = (max_teilnehmer > 0) ? min(anzahl_teilnehmer, max_teilnehmer) : anzahl_teilnehmer

eff_Tage = (max_tage > 0) ? min(anzahl_tage, max_tage) : anzahl_tage

// Subtotal berechnen

subtotal = grundbetrag

+ betrag_pro_teilnehmer × eff_TN

+ betrag_pro_tag × eff_Tage

+ zusatzbetrag ← aus der Trainerart-Zeile

// Eventart-Multiplikator anwenden

total = subtotal × multiplikator ← aus der Eventart-Zeile

Schritt 3

Deckelung (Cap)

if (betrag_max_gesamt > 0):

total = min(total, betrag_max_gesamt)

// 0 bedeutet kein Limit – total wird unverändert übernommen

Rückgabe

Ergebnis-Array

Feld Typ Beschreibung
berechtigt boolean true wenn Trainer- und Eventart passen
grund string|null Nur wenn berechtigt = false: Ablehnungsgrund
betrag float Berechneter Förderbetrag in CHF (gerundet auf 2 Dezimalstellen)
aufschluesselung array Detail: grundbetrag, tn_anteil, tage_anteil, trainer_zusatz, eventart_faktor

9. Berechnungsbeispiele

Basierend auf den drei Beispiel-Subventionen aus den Seed-Daten

Subvention 1

J+S Lagerbeitrag Segeln

Förderstelle: BASPO / J+S

Konfiguration

GrundbetragCHF 0.00
Pro TeilnehmerCHF 12.00
Pro TagCHF 8.00
Max. Teilnehmer40
Max. Tage14
Max. GesamtCHF 3'000.00
Trainer (Zusatz)js_trainer (+150.00)
Eventart (Faktor)lager (×1.000)

Simulation: 20 TN, 5 Tage, J+S Trainer, Lager

eff_TN = min(20, 40) = 20

eff_Tage = min(5, 14) = 5

subtotal = 0.00

+ 12.00 × 20 = 240.00

+ 8.00 × 5 = 40.00

+ 150.00 (Trainer)

= 430.00

total = 430.00 × 1.000 = 430.00

Cap 3'000 → kein Einfluss

Ergebnis: CHF 430.00

Konfiguration
